# Process execution

Use the target Neovim installation’s help for version-specific signatures and behavior (start with `:help vim.system()`). For other versions, consult the matching release’s documentation. The online [process execution documentation](https://neovim.io/doc/user/lua.html) tracks current Neovim and may differ from the target. Relevant help topics: vim.system().

Prefer documented public APIs; names beginning with `_` are internal. Check `:help deprecated` before using older APIs.
