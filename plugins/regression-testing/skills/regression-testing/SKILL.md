# Regression testing

Identify the behavior at risk and inspect the project's existing tests and commands. For a bug fix, add a focused regression test when practical and valuable; confirm it catches the original failure when feasible. Select the smallest useful test layer and run relevant checks, expanding to the full suite when warranted by the change or project instructions. Report failures, pre-existing issues, and checks that could not be run. Avoid tests that merely repeat implementation details.
