# Tree-sitter apis

Use the target Neovim installation’s help for version-specific signatures and behavior (start with `:help treesitter`). For other versions, consult the matching release’s documentation. The online [Tree-sitter APIs documentation](https://neovim.io/doc/user/treesitter.html) tracks current Neovim and may differ from the target. Relevant help topics: treesitter.

Prefer documented public APIs; names beginning with `_` are internal. Check `:help deprecated` before using older APIs.
